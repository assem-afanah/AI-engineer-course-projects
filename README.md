# AI-engineer-course-projects
The repository contains 4 sub-directories : Data eingineering, Maschine learning, Deep learning, Reinforcment learning. Which were presented as part of the cetificate "AI engineer".
**Data eingineering projects:** Constructing a data warehouse from the LinkedIn Job Postings Dataset enables systematic integration, cleaning, and historical tracking of job market data to support business intelligence (BI) and strategic decision-making.
**Machine learning projects:** This project develops a machine learning model that predicts the number of rented bicycles based on historical data. The analysis is based on the London Bike Sharing Dataset, which, in addition to information on the number of bike rentals, also contains various influencing factors such as weather conditions, time variables, and seasonal effects.
**Deep learning projects:** classification and segmentation of brain tumor cancer MRI images and CRC Multiplex Tissue Imaging — Cell Clustering with HFcluster
**Reinforcement learning projects:** the workbench trains and compares three algorithms — **A2C**, **SAC**, and **TD3** — using **Stable-Baselines3 (SB3)** on
the `Ant-v5` MuJoCo/Gymnasium environment.  A Tkinter GUI provides full hyperparameter control, live side-by-side reward charts, per-algorithm progress bars, 
a live animation popup, a score comparison table, and **per-algorithm model save/load** so any trained policy can be persisted
and resumed later with different hyperparameters.
